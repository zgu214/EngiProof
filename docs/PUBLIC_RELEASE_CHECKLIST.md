# Public release checklist

- [ ] `python -m unittest discover -s tests -v` passes.
- [ ] `engiproof verify-all` passes or returns only expected `PASS_SOURCE_EXTERNAL` states.
- [ ] No source PDFs are tracked.
- [ ] No client/project confidential data is tracked.
- [ ] No absolute local machine paths are tracked.
- [ ] No credentials/tokens/API keys are tracked.
- [ ] Every live study has a source contract and explicit evidence class.
- [ ] Fitted/regression results are not labelled independent physics.
- [ ] Source inconsistencies are retained and documented.
- [ ] Release tag and `CITATION.cff` version match.

\section{Reproducibility checklist}
Before submission, the following items must be regenerated directly from the tagged repository state:
\begin{itemize}[leftmargin=1.5em]
  \item software version, commit, and release DOI if available;
  \item study registry and evidence-status table;
  \item P40 and P41 comparison CSV/JSON artifacts;
  \item discrepancy assessments and human-decision records;
  \item evidence-graph audits;
  \item exact test count and supported Python versions;
  \item all manuscript numerical tables from machine-readable results rather than manually copied values.
\end{itemize}

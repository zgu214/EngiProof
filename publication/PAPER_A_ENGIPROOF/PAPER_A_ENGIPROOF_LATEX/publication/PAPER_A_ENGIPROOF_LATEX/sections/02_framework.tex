\section{Evidence architecture}
\label{sec:framework}

\subsection{Evidence classes and outcomes}
\engiproof{} separates the \emph{origin} of a result from its \emph{maturity}. Every callable method and every evidence node carries one of three evidence classes. \eclass{PUBLISHED} denotes a source-bounded implementation of a method, or a value as printed. \eclass{INDEPENDENT} denotes a methodologically independent formulation or numerical method applied to the same quantity. \eclass{SOLVER\_NEW} denotes newly generated solver evidence; the class is defined in the contracts but no study uses it yet (PA-25), and it is reserved for solver adapters.

Each comparison target carries one of five outcomes. A target is \estatus{REPRODUCED} when the published value is regenerated to source precision, and \estatus{COMPARED} when agreement or disagreement is quantified against a published reference population. \estatus{CONDITIONAL} marks a comparison that holds only under a stated source ambiguity, and \estatus{BLOCKED} marks a target for which the source lacks the inputs, with the missing items named. \estatus{VERIFIED} is reserved and is used by no comparison in the six cases.

Across all six studies, the evidence status is \estatus{CONDITIONAL} and engineering qualification is \estatus{NOT\_GRANTED}; execution alone changes neither. The contracts are versioned, machine-readable JSON (\texttt{engiproof/\allowbreak{}contracts/\allowbreak{}contracts.json}).

\subsection{Lifecycle}
Figure~\ref{fig:lifecycle} shows the lifecycle, in which every arrow is a controlled transition with its own record. An extraction candidate does not become evidence because it was recognised, a callable method does not become qualified because it returns a number, and a discrepancy is not closed because a later step agrees with one of its sides.

\subsection{Rules enforced by the repository}
The following rules are part of the repository contract (\texttt{AGENTS.md}), not guidance, and tests and gates enforce them where possible:
\begin{enumerate}[leftmargin=1.6em]
  \item \eclass{PUBLISHED}, \eclass{INDEPENDENT} and \eclass{SOLVER\_NEW} are preserved.
  \item Extraction candidates are not evidence.
  \item Code execution is not verification, and verification is not qualification.
  \item Unknown source inputs are never tuned to force agreement.
  \item Published inconsistencies are never silently corrected.
  \item Copyrighted sources are not redistributed; the SHA-256 is kept instead.
  \item No machine-specific paths are persisted.
\end{enumerate}
In addition, every evidence-producing calculation has persistent runnable code, traceable inputs and results, and tests.

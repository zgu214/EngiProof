\section*{Data, software and source boundary}
The EngiProof software repository is cited as software in this draft. Copyrighted source PDFs and publisher raster figures are intentionally not redistributed by EngiProof. Source fingerprints, bibliographic identifiers, bounded source locators, independently generated calculations, and machine-readable evidence records are used instead. All numerical statements trace to repository artifacts listed in Appendix~\ref{app:repro}.

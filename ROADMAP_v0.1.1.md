# EngiProof v0.1.1 Roadmap

## Release objective
Turn EngiProof from a two-study prototype into a reusable engineering-evidence runtime.

Path: published source -> source contract -> reproducible calculation -> independent check -> published comparison -> discrepancy analysis -> evidence classification -> callable method -> verification record.

## Priorities
1. Generic Study/Source/Evidence/Comparison/Discrepancy/Verification contracts.
2. P38 as first complete evidence-chain study.
3. P16/P29/P36 subject to source readiness.
4. Machine-readable provenance and evidence graph.
5. Backward-compatible CLI/JSON.
6. Tests and Python 3.10/3.12/3.13 CI.

## Non-goals
No GUI-first work, no new FE solver, no unsupported qualification claims, and no bulk paper count without reproduction evidence.

## Current checkpoint
P38 integration batch implemented and locally verified; see `PROGRESS_v0.1.1.md`.

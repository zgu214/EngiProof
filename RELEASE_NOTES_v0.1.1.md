# EngiProof v0.1.1 — engineering evidence runtime

EngiProof v0.1.1 expands the initial public prototype into a reusable, source-bounded engineering-evidence runtime.

## Highlights

- Six live studies: P08, P12, P16, P29, P36 and P38.
- Versioned generic Study, Source, Evidence, Comparison, Discrepancy and Verification contracts.
- Machine-readable CLI queries for `schema`, `evidence`, `compare`, `discrepancy` and `provenance`.
- P38 complete evidence chain: source identity → reproduction → independent work-balance check → comparison → open discrepancy → callable tools → verification record.
- P16 published Figure-5/Table-2 walking consistency audit.
- P29 independent state-space and transfer-function quadrature cross-check, while preserving the unresolved source factor-of-two convention as `CONDITIONAL`.
- P36 Eq. (8) audit against 27 source Figure-14 graphical FE marker centres.
- Backward compatibility retained for P08/P12 callable tools and study manifests.
- Python 3.10/3.12/3.13 CI remains required.

## Evidence status

- P08 — `COMPARED`
- P12 — `COMPARED`
- P16 — `COMPARED`
- P29 — `CONDITIONAL`
- P36 — `COMPARED`
- P38 — `CONDITIONAL`

`CONDITIONAL` is intentional where a source discrepancy remains unresolved. A passing calculation or test does not automatically promote evidence to `VERIFIED` or grant engineering qualification.

## Distribution boundary

Copyrighted source PDFs and source raster figures are not redistributed. Source identifiers and expected SHA-256 values are retained for local verification. This release does not claim new FE reproduction for studies where none was performed and does not grant engineering qualification.

# EngiProof intake workspace

This folder is the local paper-intake workspace. Original PDFs are **not copied here by default**.

Generated per-paper intake directories may contain:

- `source_fingerprint.json`
- `target_candidates.json`
- `source_map.json`
- `target_dossiers.json`
- `structure_candidates.json`
- `reproduction_tasks.json`
- `comparison_templates.json`
- `ingestion.json`
- `reproduction_plan.json`
- `REVIEW.md`

Per-paper intake directories are ignored by Git by default because bounded source excerpts and private paper-derived metadata can appear in them. This README remains tracked.

Intakes are deliberately separate from the live study registry. Automatic discovery, extraction, task generation or comparison-template generation does not establish engineering evidence.
